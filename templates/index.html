How to set up Google Sheets
  1. 1Open Google Cloud → IAM → Service Accounts and create a new service account.
  2. 2Click the service account → Keys → Add Key → JSON. A JSON file will download.
  3. 3Enable the Google Sheets API in the same project.
  4. 4In your Railway / Replit environment, create a secret named GOOGLE_SERVICE_ACCOUNT_JSON and paste the entire contents of the JSON file.
  5. 5Restart the app and return here — this panel will update automatically.
